**MoneyVaults: Finance & FIRE** is a modern, privacy-focused, offline-first personal wealth and financial freedom application. Designed to organize your capital into dedicated smart vaults, track cash flow with zero friction, automate recurring reminders, and project exponential compound interest growth toward early retirement (FIRE).

---

## 🌟 Core Features

* **🗄️ Smart Dedicated Financial Vaults:**  
  Segment capital into dedicated vaults: **Savings Goals (Piggy Banks)**, **Emergency Runway Funds**, **Investment Portfolios**, and **Operational Spending Accounts**. Customize initial balances, icons, and matching colored progress bars.
* **🔁 Recurring Transactions & Smart Device Alerts:**  
  Set recurring reminders for rent, salaries, subscriptions, and investments with customizable recurrence intervals ($x$ Days, Weeks, Months, or Years), target days of month (1–31), and specific notification times. Receive local device push notifications with instant **"Confirm & Log"** or **"Skip"** options.
* **📈 Exponential Compound Growth & FIRE Engine:**  
  Simulate long-term capital accumulation with interactive charts, monthly contributions, annual return projections, and month-by-month compounding tables.
* **⚡ One-Tap Fastfill:**  
  Log recurring daily expenses in under two seconds with configurable quick-step increment buttons.
* **📊 Portfolio Asset Allocation:**  
  Real-time asset weighting and liquid-to-invested ratios with visual distribution bars to maintain ideal balance.
* **🧮 Financial Calculators Suite:**  
  - Compound Interest & FIRE Planner  
  - Dividend Growth & Reinvestment (DRIP) Simulator  
  - Loan Amortization & Early Payoff Table  
  - Smart Discount & Pricing Comparison Tool
* **👁️ Compact & Expanded View Modes:**  
  Switch between rich detailed cards and high-density compact lists across vaults, cash flows, and recurring schedules.
* **🔒 100% Offline-First Privacy & Data Center:**  
  Zero account registration required, zero third-party financial tracking. Export and restore your complete portfolio in encrypted JSON or backup directly to Google Drive, iCloud, or local storage.

## 🚀 Building & Running from Source

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.13+)
- Dart SDK (3.13+)
- Android Studio / Android SDK (Platform 34 / Java 17)

### Quick Start
```bash
# Clone the repository
git clone https://github.com/compoundlysupport/MoneyVault-Privacy.git
cd MoneyVault-Privacy

# Install dependencies
flutter pub get

# Run static analysis
flutter analyze

# Run all unit and widget tests
flutter test

# Run app in debug mode
flutter run

# Build production Android App Bundle (AAB)
flutter build appbundle --release
```
